# Настройка Ollama для AIAdventChat

## Установка Ollama

### macOS
```bash
brew install ollama
```

Или скачайте с официального сайта: https://ollama.ai

### Запуск сервера Ollama
```bash
ollama serve
```

Сервер будет доступен на `http://localhost:11434`

## Загрузка моделей

Рекомендуемые модели для разных целей:

### Маленькие и быстрые модели (для начала)
```bash
ollama pull llama3.2:1b      # ~1GB, очень быстрая
ollama pull phi3:mini         # ~2GB, качественная
ollama pull gemma:2b          # ~2GB
```

### Средние модели (хорошее качество)
```bash
ollama pull llama3.1:8b       # ~4.7GB
ollama pull mistral:7b        # ~4.1GB
ollama pull qwen2.5:7b        # ~4.7GB
```

### Специализированные модели
```bash
ollama pull deepseek-r1:7b    # ~4.7GB, с reasoning
ollama pull codellama:7b      # ~4.1GB, для кода
```

### Список загруженных моделей
```bash
ollama list
```

## Настройка в приложении

1. Откройте `local.properties` в корне проекта
2. Добавьте или измените строку:

```properties
OLLAMA_BASE_URL=http://10.0.2.2:11434/
```

**Важно:**
- `http://10.0.2.2:11434/` - для Android эмулятора (10.0.2.2 это localhost для эмулятора)
- `http://192.168.x.x:11434/` - для реального устройства (замените на IP вашего компьютера)

### Как узнать IP адрес вашего Mac:
```bash
ifconfig | grep "inet " | grep -v 127.0.0.1
```

## Использование в приложении

1. Запустите приложение
2. Откройте **Настройки** (иконка шестеренки)
3. Выберите **API провайдер и модель**
4. Выберите **Ollama (локальный)**
5. Введите название модели (например: `llama3.2:1b`, `mistral:7b`)
6. Нажмите **Сохранить**

## Тестирование подключения

Проверьте доступность Ollama API:

```bash
# Проверка списка моделей
curl http://localhost:11434/api/tags

# Тест генерации
curl http://localhost:11434/api/generate -d '{
  "model": "llama3.2:1b",
  "prompt": "Why is the sky blue?",
  "stream": false
}'
```

## Сравнение моделей (для учебного задания)

Для сравнения разных моделей используйте:

1. **Маленькая модель:** `llama3.2:1b` или `phi3:mini`
2. **Средняя модель:** `mistral:7b` или `llama3.1:8b`
3. **Большая модель:** `qwen2.5:7b` или `deepseek-r1:7b`

### Что сравнивать:
- Время ответа (меньше = лучше)
- Количество токенов
- Качество ответов (субъективная оценка)
- Потребление памяти

## Переключение между DeepSeek и Ollama

Вы можете легко переключаться между облачным API (DeepSeek) и локальным (Ollama) в настройках приложения.

**DeepSeek:**
- ✅ Качественные ответы
- ✅ Не требует мощного ПК
- ❌ Требует интернет
- ❌ Платный (но дешевый)

**Ollama:**
- ✅ Бесплатный
- ✅ Работает офлайн
- ✅ Полный контроль
- ❌ Требует мощный ПК
- ❌ Нужно скачивать модели

## Устранение проблем

### Ошибка: "CLEARTEXT communication not permitted"
Эта ошибка означает, что Android блокирует незащищенный HTTP трафик.

**Решение (уже реализовано в проекте):**
- Файл `app/src/main/res/xml/network_security_config.xml` разрешает HTTP для localhost
- `AndroidManifest.xml` настроен на использование этого конфига
- Просто пересоберите проект: **Build → Clean Project** → **Build → Rebuild Project**

**Если проблема осталась:**
1. Проверьте, что в `local.properties` указан правильный URL
2. Убедитесь, что используете `http://` а не `https://`
3. Для реального устройства добавьте ваш IP в `network_security_config.xml`:
   ```xml
   <domain includeSubdomains="true">192.168.x.x</domain>
   ```

### Ошибка подключения
- Убедитесь, что Ollama запущена: `ollama serve`
- Проверьте URL в `local.properties`
- Для реального устройства убедитесь, что устройство и компьютер в одной сети

### Модель не найдена
- Загрузите модель: `ollama pull название_модели`
- Проверьте список моделей: `ollama list`
- Убедитесь, что в настройках указано точное название модели

### Медленная работа
- Используйте модели меньшего размера (1b, 2b, 3b)
- Закройте другие приложения
- Убедитесь, что у вас достаточно RAM (минимум 8GB для 7b моделей)

## Полезные команды

```bash
# Удалить модель
ollama rm название_модели

# Информация о модели
ollama show название_модели

# Обновить модель
ollama pull название_модели

# Остановить Ollama
killall ollama
```
