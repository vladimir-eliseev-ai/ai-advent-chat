# Настройка GitHub MCP Server

Приложение настроено для работы с официальным GitHub MCP Server через HTTP транспорт.

## URL сервера (зафиксирован в приложении):
- `https://api.githubcopilot.com/mcp/`

## Получение GitHub Personal Access Token (PAT)

### Шаг 1: Создайте токен
1. Перейдите: https://github.com/settings/tokens
2. Нажмите "Generate new token" → "Generate new token (classic)"
3. Введите название: "MCP Android App"

### Шаг 2: Выберите права (Scopes)

**ОБЯЗАТЕЛЬНЫЙ scope** (без него будет ошибка "forbidden"):
- ✅ `repo` — **ОБЯЗАТЕЛЬНО** для работы с репозиториями

Дополнительные права (опционально):
- `read:org` — чтение организаций
- `read:packages` — работа с пакетами
- `gist` — работа с gist
- `notifications` — уведомления

**ВАЖНО:** Если при подключении возникает ошибка "forbidden: access denied", проверьте, что токен имеет scope `repo`.

### Шаг 3: Создайте и скопируйте токен
1. Нажмите "Generate token"
2. **Скопируйте токен сразу** — он показывается только один раз
3. Сохраните токен в безопасном месте

## Использование в приложении

1. Откройте экран "MCP ИНСТРУМЕНТЫ"
2. Вставьте ваш GitHub PAT в поле токена
3. Нажмите "Подключиться"
4. Просмотрите список доступных инструментов

### Доступные инструменты:
GitHub MCP Server предоставляет множество инструментов для работы с:
- Репозиториями (чтение файлов, создание веток, коммиты)
- Issues (создание, обновление, поиск)
- Pull Requests (создание, ревью, мердж)
- GitHub Actions (запуск воркфлоу, просмотр логов)
- Code Security (сканирование, Dependabot)
- И многое другое

**Документация**: https://github.com/github/github-mcp-server

## Вариант 1: Простой Python сервер (Для тестирования)

### Требования:
- Python 3.8+
- pip

### Установка зависимостей:
```bash
pip install fastapi uvicorn
```

### Запуск сервера:
```bash
python test_mcp_server.py
```

Сервер будет доступен на:
- **Локально**: `http://localhost:8000/mcp`
- **Для Android эмулятора**: `http://10.0.2.2:8000/mcp`
- **Для реального устройства**: `http://<IP_вашего_компьютера>:8000/mcp`

### Использование в приложении:
Введите в поле URL: `http://10.0.2.2:8000/mcp` (для эмулятора)

## Вариант 2: Использование MCP Framework (Node.js)

### Требования:
- Node.js 18+

### Установка:
```bash
npm install -g @modelcontextprotocol/framework
```

### Создание простого сервера:
```bash
mcp create test-server --http --port 8000 --cors
cd test-server
npm install
npm start
```

## Рекомендации для тестирования

1. **Для быстрого тестирования**: Используйте Вариант 1 (Python сервер)
2. **Для разработки**: Запустите локальный сервер и используйте IP вашего компьютера
3. **Для эмулятора**: Используйте `10.0.2.2` вместо `localhost`

## Проверка работы сервера

После запуска сервера, откройте в браузере:
- `http://localhost:8000/` - должна отобразиться информация о сервере
- `http://localhost:8000/mcp` - основной MCP endpoint

## Устранение проблем

### Сервер не запускается:
- Проверьте, что порт 8000 свободен
- Убедитесь, что установлены все зависимости

### Android приложение не подключается:
- Для эмулятора используйте `10.0.2.2` вместо `localhost`
- Для реального устройства убедитесь, что телефон и компьютер в одной сети
- Проверьте, что сервер запущен и доступен

### Ошибка CORS:
- Python сервер уже настроен с CORS для всех источников
- Если используете другой сервер, убедитесь, что CORS включен
