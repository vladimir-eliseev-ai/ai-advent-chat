# Запуск на эмуляторе Android

Эмулятор обращается к хосту по адресу **10.0.2.2** (не localhost).

## 1. local.properties

В корне проекта в `local.properties` задайте (или оставьте по умолчанию):

```properties
# Адрес хоста с точки зрения эмулятора
MCP_BASE_URL=http://10.0.2.2
# Опционально: Ollama на хосте
OLLAMA_BASE_URL=http://10.0.2.2:11434/
```

Если `MCP_BASE_URL` не задан, в приложении используется `http://10.0.2.2`.

## 2. Запуск MCP-серверов на хосте

Серверы должны слушать **все интерфейсы** (`0.0.0.0`), чтобы эмулятор мог к ним подключаться. В проекте это уже настроено.

В отдельных терминалах на компьютере:

```bash
# Статья: чтение (порт 8082)
./gradlew :article-reader-mcp-server:run

# Статья: резюме (порт 8083), нужен DEEPSEEK_API_KEY для LLM
DEEPSEEK_API_KEY=sk-... ./gradlew :article-summarizer-mcp-server:run

# Хранение резюме (порт 8084)
./gradlew :summary-storage-mcp-server:run
```

Новости (если нужны):

```bash
./gradlew :newsapi-mcp-server:run
# Порт 8080
```

## 3. Запуск приложения в эмуляторе

1. Соберите и установите приложение на эмулятор (Run в Android Studio).
2. Убедитесь, что эмулятор и хост в одной сети (для эмулятора это всегда так).
3. В приложении: «Краткое резюме статьи» и «Сохранённые статьи» будут ходить на `10.0.2.2:8082`, `10.0.2.2:8083`, `10.0.2.2:8084`.

## Порты

| Сервис              | Порт |
|---------------------|------|
| article-reader      | 8082 |
| article-summarizer  | 8083 |
| summary-storage     | 8084 |
| newsapi             | 8080 |

## Кнопка «Поднять окружение (Docker)»

Чтобы приложение могло вызывать `docker compose up -d`, на **хосте (ПК)** должен быть запущен оркестратор (порт 8090). В каталоге проекта выполните:

```bash
COMPOSE_DIR=$(pwd) ./gradlew :environment-orchestrator:run
```

После этого в приложении нажмите «Поднять окружение (Docker)». Оркестратор выполнит `docker compose up -d` в этой директории.

## Если не подключается

- Проверьте, что все нужные серверы запущены на хосте.
- Для оркестратора: сначала запустите `./gradlew :environment-orchestrator:run` (см. выше), затем используйте кнопку в приложении.
- На хосте: `curl http://localhost:8082` (и другие порты) — должен отвечать MCP/SSE; для оркестратора: `curl http://localhost:8090`.
- В эмуляторе тот же хост доступен как `http://10.0.2.2:8082` и `http://10.0.2.2:8090`.
