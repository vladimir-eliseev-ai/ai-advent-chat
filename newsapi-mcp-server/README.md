# NewsAPI MCP Server

MCP сервер для получения последних новостей из NewsAPI.

## Возможности

- ✅ Получение 5 последних новостей
- ✅ Поддержка поиска по запросу
- ✅ Поддержка разных языков (ru, en и др.)
- ✅ Возвращает заголовки, описания, ссылки и даты публикации

## Установка

### 1. Получите API ключ

Зарегистрируйтесь на https://newsapi.org/ и получите бесплатный API ключ для разработки.

### 2. Соберите проект

```bash
cd newsapi-mcp-server
./gradlew shadowJar
```

Это создаст JAR файл: `build/libs/newsapi-mcp-server-1.0.0.jar`

### 3. Подключение к Cursor

Добавьте в `~/.cursor/mcp.json`:

```json
{
  "mcpServers": {
    "newsapi": {
      "command": "java",
      "args": [
        "-jar",
        "/полный/путь/к/AIAdventChat/newsapi-mcp-server/build/libs/newsapi-mcp-server-1.0.0.jar"
      ],
      "env": {
        "NEWS_API_KEY": "ваш_api_ключ_здесь"
      }
    }
  }
}
```

**Важно:** Замените `/полный/путь/к/` на реальный путь к проекту и вставьте свой API ключ.

### 4. Перезапустите Cursor

После изменения `mcp.json` полностью закройте и откройте Cursor заново.

## Использование

После подключения агент сможет вызывать инструмент `get_latest_news`:

- **Без параметров**: вернет 5 последних новостей на русском
- **С параметром `query`**: поиск новостей по запросу
- **С параметром `language`**: выбор языка (ru, en и др.)

## Примеры использования

- Получить последние новости: `get_latest_news()`
- Поиск новостей о технологиях: `get_latest_news(query="технологии")`
- Новости на английском: `get_latest_news(language="en")`
- Поиск на английском: `get_latest_news(query="technology", language="en")`

## Проверка работы

После подключения в Cursor спроси агента:
- "Получи последние новости"
- "Найди новости о технологиях"
- "Покажи новости на английском языке"

Агент должен вызвать инструмент `get_latest_news` и вернуть список из 5 новостей.

## Решение проблем

### Ошибка "API key missing or invalid"
- Проверьте, что переменная окружения `NEWS_API_KEY` установлена правильно
- Убедитесь, что API ключ действителен на https://newsapi.org/

### Сервер не запускается
- Убедитесь, что Java установлена: `java -version`
- Проверьте путь к JAR файлу в `mcp.json`

### Агент не видит инструмент
- Перезапустите Cursor полностью
- Проверьте логи Cursor на наличие ошибок подключения
