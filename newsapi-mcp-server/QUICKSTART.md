# Быстрый старт NewsAPI MCP Server

## Шаг 1: Получите API ключ

1. Зайдите на https://newsapi.org/
2. Нажмите "Get API Key"
3. Зарегистрируйтесь (бесплатно для разработки)
4. Скопируйте ваш API ключ

## Шаг 2: Соберите проект

```bash
cd newsapi-mcp-server
./gradlew shadowJar
```

После сборки JAR файл будет здесь:
`build/libs/newsapi-mcp-server-1.0.0.jar`

## Шаг 3: Настройте Cursor

Откройте `~/.cursor/mcp.json` и добавьте:

```json
{
  "mcpServers": {
    "newsapi": {
      "command": "java",
      "args": [
        "-jar",
        "/Users/Eliseev.Vladimir20/AndroidStudioProjects/AIAdventChat/newsapi-mcp-server/build/libs/newsapi-mcp-server-1.0.0.jar"
      ],
      "env": {
        "NEWS_API_KEY": "ВАШ_API_КЛЮЧ_ЗДЕСЬ"
      }
    }
  }
}
```

**Важно:** Замените путь на ваш реальный путь к проекту!

## Шаг 4: Перезапустите Cursor

Полностью закройте и откройте Cursor заново.

## Шаг 5: Проверьте работу

В Cursor спросите агента:
- "Получи последние новости"
- "Найди новости о технологиях"

Агент должен вызвать инструмент `get_latest_news` и вернуть список из 5 новостей! ✅

## Что дальше?

После успешного подключения агент сможет:
- ✅ Получать последние новости
- ✅ Искать новости по запросу
- ✅ Получать новости на разных языках

**Результат задания:** Агент делает вызов к вашему инструменту и получает результат! 🎉
